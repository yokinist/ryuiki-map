      アプリについて・利用上の注意

      個人（yokinist）が非商用で開発している、日本に降った雨がどの流域を通ってどの海へ流れ着くかをたどれる探索マップです。ソースコードは GitHub で公開しています。不具合の報告や改善の提案（Issue）、Pull Request を歓迎します。

      利用上の注意

      • 試作段階のアプリです。データや計算に誤りが含まれている可能性があります。
      • 対象は日本国内の陸地です（標高・河川データの範囲）。国外や遠く離れた海は選べません。
      • 流れの向きは標高タイル（約10〜240mメッシュ）から計算した推定です。平地・市街地・用水路のある場所では実際と異なることがあります。
      • 川の名前と河川線は OpenStreetMap のものです。日本の河川線の多くは国土数値情報（河川データ）2006年度版を取り込んだもので、その後の改修や名称の変更は反映されていないことがあります。
      • 地区名は地理院の逆ジオコーダによる大字単位の目安です。
      • 海の名前は国際水路機関（IHO）の海域区分によります。関東以西の太平洋側（IHO の区分ではフィリピン海）も太平洋と表示しています。
      • 所要時間は流速1m/sと仮定したおおよその目安です。
      • 流域サマリの人口は1kmメッシュの人口を面積で按分した推定、土地の使われ方は衛星画像の分類（約70mに縮小して集計）、年間降水量は範囲の中心1地点の再解析値で、どれも目安です。ダム・堰は OpenStreetMap に登録されているものだけを数え、雨の通り道・水の来た道には流路から約250m以内のものを出しています。
      • 防災・測量・ナビゲーションなど、正確さが求められる用途には使えません。
